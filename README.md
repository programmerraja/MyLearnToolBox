# MyLearnToolBox

Practical, hands-on learning. One folder per tech. Each lesson is a real problem: you write the fix, a script checks it.

```
<tech>/
  README.md          # how to run
  roadmap.md         # the problems, in order
  infra/             # shared setup scripts
  concepts/NN-slug/  # notes.md (problem + hints), data, naive, solution (yours), check.sh
```

Add a new tech: ask for a learning path (see `.cursor/skills/problem-driven-learning`).
